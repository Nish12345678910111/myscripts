Description

Booth Hopper

Auto-claims a booth, then hops to a new server and does it again. Built for mobile and PC executors.

Features

- Auto claim: Attempts to claim a booth and checks whether the claim succeeded.
- Cart ID input: Lets you enter a cart ID and saves it for future servers.
- Booth mode selector: Choose the same booth or a random booth.
- Smart server hopping: Skips full and previously visited servers.
- Endless rounds: Starts a new round after visiting available servers.
- Mobile-friendly GUI: Includes Start, Stop, Reset IDs, status information, and minimize controls.
- Auto-continue: Attempts to resume after teleporting.

Requirements

The script requires executor support for "writefile", "readfile", "delfile", "queue_on_teleport", and an HTTP request function.
